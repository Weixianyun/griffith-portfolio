# 鷹の団 · Gr1ff1th — 个人博客 / 作品集

> "光之鹰展翅翱翔。白银之翼，蔚蓝之瞳。"

A personal blog / portfolio built with Vue 3 + Vite 5, deployed on Vercel.

## Stack

- Vue 3 (Composition API) + Vite 5
- Dual theme (Griffith Light / Femto Dark)
- Glassmorphism UI + CSS variables
- GitHub stats sync (5 min localStorage cache)
- Interactive calendar + site stats + tag cloud
- Responsive 3-column layout
- Vercel one-click deploy

## Develop

```bash
npm install
npm run dev
npm run build
```
